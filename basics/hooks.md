# React Hooks
React hooks enable functional components to use state, lifecycle hooks and other react features without relying on class components.

- state hooks
    - useState
    - useReducer
- Context hooks
    - useContext
- Effect hooks
    - useEffect
    - useLayoutEffect
    - useInsertionEffect
- Performance hooks
    - useMemo
    - useCallback
- Resource Hooks
    - useRef
- custom Hooks
